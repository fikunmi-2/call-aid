# SBAR publication simplification

The publication projection now preserves every approved structured symptom and background category. There is no rejection based on more than two associated symptoms, more than one background category, more than twelve values, or their combinations. `specific_combination` is no longer emitted by application code. Historical database failure codes remain untouched.

Only enumerated facts and deterministic SBAR/rule templates reach persistence. Existing broad `other`, `health_context` and `medication_context` categories retain their fixed descriptions without their original details. Answers without a faithful supported mapping remain unknown. Source identifiers are omitted while unrelated validated categories survive. Empty or partial sessions can produce a minimal incomplete report with unknown fields; they are never mislabeled completed.

New records carry `assessment.public_data_handling` with `policy_version: projection-1.1`, the generalized field names, and a boolean indicating omitted details. The dashboard/report component explains generalization and omission. No arbitrary explanation field is allowed. Existing schema 3.0 reports without this optional metadata remain readable. The database's existing `public-1.0` persistence-envelope version is unchanged; the nested projection version distinguishes this policy revision.

The trusted finalizer still waits for confirmed persistence before the agent announces success, exposes a case ID, or shows a report link. Invalid application/schema state is a technical failure without a raw-content fallback. Database errors retain bounded retries and truthful failure messages. Legacy withheld states remain readable as operational outcomes, but ordinary conversation complexity no longer creates them.

No new migration, environment variable, authentication, service or infrastructure is needed. Existing migrations 001–004 and privileged RPC access remain in place; no hosted migration/reset was performed. Previously withheld content cannot be reconstructed or republished because it was never stored. Start a new conversation to exercise the revised policy.
